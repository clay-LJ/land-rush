# LAND RUSH v1.1
브라우저에서 실행하는 땅따먹기 순위 게임입니다. 서버·계정·DB가 필요 없습니다.

## 실행
index.html을 열거나 이 폴더의 정적 파일을 GitHub Pages 루트에 올리세요.

## 기능
- 2~500명, 같은 이름 합산, 1인 시작 땅1~100칸
- 고정300×180 지도, 무작위 연결 초기영토
- 점령전과 선택 가능한 공중폭격
- 1/2/4/8/10배속, 일시정지, 효과음/볼륨
- 참가자 추적, TOP10, 동시탈락 미니게임, 최종순위CSV
- 반응형 표시, 전체화면과 복귀
- 실제 광고/분석/외부 결제 연결 없음

## 배포
GitHub 저장소 루트에 index.html, style.css 및 JavaScript파일들을 올리고 Settings > Pages에서 main브랜치/(root)를 선택하세요. .nojekyll 포함.

v1.1은 화면 배치와 효과음을 개선한 업데이트입니다. 모바일 실기기는 별도 검증이 필요합니다.

## 화면 구성
소개 배너 없이 설정·경기장·순위를 바로 표시합니다. PC 경기장은 화면 높이에 맞추며 모바일은 세로 흐름을 유지합니다.
광고는 연결하지 않고 자리 표시나 빈 공간도 만들지 않습니다. 향후 좌우 광고는 콘텐츠 바깥 여백에, 하단 광고는 푸터 뒤에 별도로 검토하되 게임 위에 겹치지 않게 합니다.

폭격 경고음·폭발음과 우승 시 1회 폭죽 연출을 제공합니다. 효과음은 사용자가 켠 뒤에만 재생되며, 음소거·음량을 따릅니다. 움직임 줄이기 설정에서는 우승 애니메이션을 생략합니다.
node test-effects.cjs

## 배치와 조작
기본 속도는 4배입니다. 참가자 변경 후 배치를 눌러 미리보기에 반영합니다. 폭격 설정과 경기 시작은 배치를 바꾸지 않으며 새 경기 준비는 마지막 초기 배치를 복원합니다. 새 무작위 배치는 배치 버튼으로 생성합니다.
node test-arrangement.cjs

## 점진적 폭격과 순위 연출
폭격은 초반 대형면적45%부터 경과시간/탈락비율에 따라100%까지 강화됩니다. 소형2~6발, 각 대형10%, 합최대60%. 표적은 지도 전체 균등난수이며 특정 참가자를 겨냥하지 않습니다. 중앙 동시탈락 스프린트는 본경기를 멈추고 완료 후 자동재개합니다. 전체 참가자 목록은 오른쪽 독립 스크롤로 표시합니다.
회귀: node test-progressive.cjs (4,320개 시드 폭격), node test-damage.cjs (48경기), node test-tie-popup.cjs, node test-roster.cjs.
공평함은 동일한 추첨/전투 규칙을 뜻하며 가중치·위치에 따른 모든 참가자의 동일 승률을 보장하지 않습니다. 시드 재현은 테스트 엔진에 주입하는 난수로 검증하며 사용자용 시드입력/리플레이 UI는 없습니다.
