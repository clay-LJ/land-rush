# LAND RUSH v1.3
브라우저에서 실행하는 정적 땅따먹기 순위 게임. 서버·계정·DB·광고·분석 연결 없음.

## 실행
index.html을 열거나 전체 정적 파일을 GitHub Pages main/(root)에 올립니다. .nojekyll 포함.

## 조작
- 2~500명, 1인 시작 땅1~100칸. 동명이름 합산.
- 참가자 변경 뒤 배치 버튼으로 시작위치를 확정. 경기 시작과 폭격 설정 변경은 위치를 바꾸지 않음.
- 새 경기 준비는 마지막 초기배치를 복원. 새 무작위 위치는 배치 버튼.
- 기본4배, 1/2/4/8/10배. 음향·볼륨·일시정지 통합줄.
- 경기규칙 모달, 전체화면/복귀, 응원 추적, 지도 TOP10.
- 탈락자 최종순위가 아래부터 누적. 우승 후 전체순위CSV.
- 중앙 동시탈락 스프린트는 본경기를 멈추고 실제시간으로 진행. 내부 일시정지 가능.

## v1.3 변경
좌우 패널 동일 크기, 참가자 입력창 확대, 규칙 모달. 탈락자만 하단부터 표시. 스프린트는 모두에게 같은 분포의 넓은 페이스·순간속도 난수를 적용하고 고유순위를 확정합니다.
초반·중반의 대형/소형 선택은50:50, 진행도2/3이상 후반은75:25입니다. 폭격 대형면적은 초반 기존기준45%부터 후반135%까지 증가. 소형2~8발, 각 대형10~12%, 합계 최대96%. 표적은 참가자를 가리지 않는 지도전체 균등난수. 강한 대형의 절대 최대범위는 지도15.525%. 가장자리·중립지·중첩으로 실제피해는 줄어듭니다.

## v1.3
최후의 저항: 상대의 절반 미만일 때 최대 4%p에 접근하는 완만한 보정. 큰 영토 우위·영토 증가에 따른 성공률 단조 증가 유지. 규칙 모달과 접경 추적 표시에 공개. SEO 메타·canonical·사이트맵 추가, 검색 노출/색인 보장 아님.

### 검증의 한계
최종 4%p와 기존 각각 44개 시드 경기(2/20/100/300/500명) 완주·고유 순위 검증. 역전 빈도 증가는 일관되게 입증되지 않았습니다. 300명 표본 평균 경기시간은 1배속 환산 319→470초로 늘었습니다. 기본4배 약117초이며 스프린트와 화면 성능 시간은 별도입니다. 최후의 저항은 약한 영토의 접경 확률 보완이지 역전·승리 보장이 아닙니다. 상세 resistance-final-4pp.json.
